# Preguntas para la entrevista.

## Modulo: Gestión de planos

### Emiliano Ramirez Ayala

- [ ] ¿Comó les gustaría evidenciar el avance de la obra? (Fotografias, uso de materiales, evidencia de planos),
- [ ] ¿Comó les gustaría que fuera "validado" como avance real? (Persona que revisa las fotografias, planos, similar manualmente, sistemas automaticos)
  - Los arquitectos optan por evidenciar el avance de la obra por medio de fotografias pre-requeridas, es decir que para un dicho avance deben solitarse ciertas fotos y desde ciertos angulos.
  - Los arquitectos también mencionan que el uso de materiales debería ser un supuesto de que la obra avanzo.
  - Una persona autorizada debe comprobar el avance en sitio; no hay preferencia por sistemas automaticos.

### Cesar A. Carrillo Paez

**1. Al visualizar un plano dentro del sistema, ¿qué elementos necesita poder consultar o identificar, por ejemplo medidas, áreas, niveles, materiales o anotaciones?**

**2. Cuando se compare un plano con una evidencia de obra, ¿qué información espera que el sistema muestre para determinar si existe alguna diferencia, que si si se cubrio o que si se puede considerar como avance?**

- Los arquitectos mencionan que al consultar un plano es importante poder identificar medidas, áreas, niveles, materiales y anotaciones que ayuden a entender correctamente la información del plano.
- También consideran importante que los planos pasen por una revisión antes de ser publicados, de manera que una persona autorizada pueda aprobarlos o rechazarlos.
- Al comparar un plano con la evidencia de obra, esperan poder identificar diferencias entre lo planeado y lo ejecutado, principalmente mediante fotografías y observaciones realizadas durante la supervisión.
- Si existe alguna diferencia, esta debe poder registrarse para que sea revisada antes de considerar el avance como válido.

### Marcos Ariciaga Valdez

- [ ] ¿Cómo manejan actualmente las nuevas versiones de un plano (revisiones, cambios adicionales, modificaciones de última hora), y necesitan que el sistema conserve un historial de versiones anteriores para consultarlas?

- [ ] Cuando se detecta una discrepancia entre el plano y la evidencia de obra, ¿qué debería pasar después? ¿quién debe ser notificado, se genera algún reporte o incidencia?

- [ ] Pregunta 1: Sí, los planos deben manejarse por versiones. Es importante que el sistema conserve un historial de las versiones anteriores, ya que con frecuencia se necesita consultar información previa, por ejemplo, las medidas ya establecidas de un área para un trabajo específico. De esta forma, si se requiere hacer algún cambio, se cuenta con esos datos de referencia listos para consultarse sin tener que volver a levantarlos.

- [ ] Pregunta 2: Cuando se detecta una discrepancia, el sistema debe notificar a la persona encargada de la obra o, en su caso, al representante asignado. Además, debe generarse un reporte en formato PDF que documente la discrepancia, incluyendo al menos: la descripción del problema, su ubicación dentro de la obra o del plano, fotografías como evidencia y el nombre de la persona que generó el reporte, entre otros datos relevantes.
